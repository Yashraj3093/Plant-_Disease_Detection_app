# 🌿 Plant Disease Detection System using AI & ML

An AI-powered Plant Disease Detection System that identifies plant leaf diseases using deep learning techniques. The system allows users to upload leaf images and receive real-time disease predictions, helping farmers and researchers improve crop health monitoring.

---

## 📌 Project Overview

Plant diseases significantly affect agricultural productivity. This project leverages **Machine Learning and Computer Vision** to automatically detect and classify plant leaf diseases from images. A Convolutional Neural Network (CNN) model is trained on labeled plant leaf datasets to provide accurate disease predictions through a user-friendly web interface.

---

## 🚀 Features

- Image-based plant disease detection  
- CNN-based deep learning classification model  
- Data preprocessing and augmentation for improved accuracy  
- Real-time prediction through web application  
- User-friendly image upload interface  
- Scalable and deployable AI model  

---

## 🧠 Technologies Used

- **Programming Language:** Python  
- **Libraries & Frameworks:** TensorFlow, Keras, OpenCV, NumPy, Pandas  
- **Machine Learning:** Convolutional Neural Networks (CNN)  
- **Web Framework:** Streamlit  
- **Dataset:** Plant leaf disease image dataset  
- **Tools:** Jupyter Notebook, Git  

---

## ⚙️ System Workflow

1. Collect and preprocess plant leaf images  
2. Apply data augmentation techniques  
3. Train CNN model for disease classification  
4. Evaluate model performance  
5. Deploy trained model into a web application  
6. Predict disease from uploaded images  

---

## 📊 Model Performance

- Improved accuracy using transfer learning  
- Optimized model with data augmentation  
- Reduced overfitting through regularization techniques
